# CLAUDE.md

This repo documents a personal Mac workflow — the tools, settings, and configurations used day-to-day.

## What this repo is

A collection of markdown files and config folders that describe how the user's Mac is set up. It is not a software project; there is no build step, no tests, and no deployable artifact.

## Structure

- `README.md` — Main list of tools and settings, organized into Core Tools, Dev Tools, and Other Things
- `terminal-setup-guide.md` — Kitty terminal setup instructions
- `neovim-setup.md` — Neovim setup instructions
- `tmux-phone-access.md` — Guide for accessing tmux from a phone
- `zed/` — Zed editor settings and keymap config

## How to edit

- When adding a new tool, place it under the appropriate section in `README.md` (Core Tools, Dev Tools, or Other Things) following the existing format: bold name, link, short description, and optional bullet points for settings/extensions.
- When adding setup guides that are longer than a few bullet points, create a separate markdown file and reference it from `README.md`.
- Keep descriptions concise and practical — this is a personal reference, not documentation for others.
