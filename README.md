# Workflow

Just documenting some of the stuff I use for my Mac workflow.

### Core Tools

**Aerospace**

[https://github.com/nikitabobko/AeroSpace](https://github.com/nikitabobko/AeroSpace)

An amazing window tiling manager.

**Raycast**

[https://www.raycast.com](https://www.raycast.com)

The better Spotlight Search.

- Settings: rebind Raycast to CMD + Space and unbind Spotlight Search default CMD + Space (System Settings)

**Homerow**

[https://www.homerow.app](https://www.homerow.app)

Keyboard shortcuts for buttons and Vim-style scroll.

### Dev Tools

**Kitty**

See `terminal-setup-guide` for full information for setup

**Neovim**

See `neovim-setup` for full information for setup

**Zed**

[https://zed.dev](https://zed.dev)

See `zed/` for settings and keymap configuration.

- Extensions: open the command palette (Shift + CMD + P), type `zed: extensions`, then search for and install **Material Icon Theme** and **Xcode Theme**

**Cursor**

[https://cursor.com](https://cursor.com)

- Settings: View > Appearance > Activity Bar Position > Top, One Dark Pro Night Flat theme

- Extensions: Vim, Rainbow CSV, Remote - SSH, Remote Explorer, Remote - SSH Editing Configuration Files, vscode-pdf, Auto Rename Tag, Better Comments, Container Tools, Dev Containers, Docker, Docker DX, gitignore, Material Icon Theme

**Xcode**

[https://developer.apple.com/xcode/](https://developer.apple.com/xcode/)

For iOS dev.

- Extensions: Vim text settings

**Android Studio**

[https://developer.android.com/studio](https://developer.android.com/studio)

For Android and KMP dev.

- Plugins: Kotlin Multiplatform, IdeaVim

**IntelliJ**

[https://www.jetbrains.com/idea/](https://www.jetbrains.com/idea/)

For Java dev.

- Plugins: IdeaVim

### Other Things

**Notes**

[https://www.icloud.com/notes](https://www.icloud.com/notes)

Default notes app that I use for everything from TODOs to... notes.

**Preview**

The default preview app for… previewing (PDFs, images, etc.).

**Microsoft Excel**

[https://excel.cloud.microsoft/en-gb/](https://excel.cloud.microsoft/en-gb/)

For number crunching.

**Claude Desktop**

[https://claude.com/download](https://claude.com/download)

Primary choice of AI + Claude Code.

- Claude Code integrations: Gmail, Google Calendar (via MCP connectors in Claude Code)

**TextEdit**

A scratchpad.

**Google Drive**

[https://www.google.com/drive/download/](https://www.google.com/drive/download/)

Cloud storage synced to MacBook via the macOS desktop app (downloaded from the web).

**Microsoft To Do**

[https://to-do.office.com](https://to-do.office.com)

Task management across devices.

**Safari**

Default browser for most tasks.

**Chrome**

Default secondary browser for... other tasks (e.g. dev tools!).

- Extensions: Ad Block, React Developer Tools

**Finder**

Default file browser.

- Settings: View > as List + CMD + J > Calculate all sizes (when needed)

**Amphetamine**

[https://apps.apple.com/ca/app/amphetamine/id937984704?mt=12Amphetamine](https://apps.apple.com/ca/app/amphetamine/id937984704?mt=12Amphetamine)

**Music**

Yeah, Apple Music.

**System Settings**

- Desktop & Dock: Automatically hide and show the Dock (on)

- Trackpad: Scroll & Zoom > Natural Scrolling (off)
